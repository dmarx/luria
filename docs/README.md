# Luria docs

What the package is and how to use it. Luria's own project memory — the
decisions, principles and development log it accumulated building itself —
is next door in [`meta/`](../meta/README.md), deliberately out of the way of
anyone reading this ([ADR-021](../meta/decisions/ADR-021.md)).

- [Project memory: how a repo thinks](project-memory.md) — the doctrine. Start
  here; this is what an agent file should point at.
- [Comment directives](directives.md) — the `inactive-ok` / `unexempt`
  vocabulary and its scope rules.
- [Adopting Luria](adopting.md) — putting the record into a project that hasn't
  got one.

The doctrine cites Luria's own record throughout, as worked examples. Those
links go to `../meta/`, and following them is optional: the reasoning is stated
where it is cited, and the citation is there so you can check it rather than
take it on faith.
