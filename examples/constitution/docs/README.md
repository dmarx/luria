# Docs

- [Values](values.md) — read whole, in order. The claims every practice here
  has to name one of.
- [Practices](practices/README.md) — situated rules, one per document, each
  grounded in a value and tagged with the surface it applies to.
- [Boundaries](boundaries/README.md) — constraints that override. The
  `overrides` edge is what makes precedence checkable instead of emphatic.
- [Sessions](sessions/README.md) — the journal, including the entry about
  writing this record.
- [The record](record.md) — what this project configured, generated.

And the source itself:

- [The source constitution](constitution.md) — the document the rest of this
  record decomposes. Hand-written, committed, and scanned by the reference
  machinery like any other prose.

Everything else is generated by `luria index`. Nothing in this directory is
committed except this file and the source: `tests/test_examples.py` builds the example into a temporary
directory, so no stale view can be committed from here.

Run it by hand:

```
cd examples/constitution
LURIA_ROOT=$PWD luria index
LURIA_ROOT=$PWD luria lint
```
