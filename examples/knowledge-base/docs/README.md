# Docs

- [Literature](literature/README.md) — one note per paper, including the attic.
- [Practices](practices/README.md) — one document per recommendation, each
  citing the note for the paper it came from.

Both are generated by `luria index`. The two schemes carry separate statuses
and are allowed to disagree about the same work.
- [The record](record.md) — what this project configured, generated.
