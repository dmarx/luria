### Changed

- The status note is its own field: `status: Superseded` with
  `status_note: by ADR-035`, where one scalar carried both. `status_note`
  is prose — a code in it is a citation the fixer links. A note still
  riding in `status:` is a lint finding, and `luria index` moves it
  ([#141](https://github.com/dmarx/luria/issues/141)).
