### Removed

- **`luria upgrade`, and the `statuses` upgrade under it.** It existed to
  carry records across [#181](https://github.com/dmarx/luria/issues/181), and every record that predated [#181](https://github.com/dmarx/luria/issues/181) has run
  it. A one-shot upgrade kept past its purpose is dead code that still has
  to be read, tested and explained.
- Lint class `spent-upgrades`, which existed to ask this question. It asked
  it, and this is the answer.

### Changed

- The finding for a scheme declaring no `status` vocabulary names the
  declaration to write rather than a command that no longer exists.
