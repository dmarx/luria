### Added

- Relation annotations on citations ([#333](https://github.com/dmarx/luria/issues/333)): `[[X]]{--F-->here}` or `[[X]]{here--F-->}` states the relation `F` in prose. An annotated edge missing from frontmatter is the new `unrecorded-relations` warning, and `luria link --fix` writes it, as this document's converse when one is declared.
- `explain: true` on a reference field asks for each code the field holds to be cited and annotated in the body. `unannotated-relations` (the fixer annotates an existing plain citation) and `unexplained-relations` (a report, acknowledged per code with the new `unexplained-ok:` directive) cover the two ways that can fail.
- `bad-annotations` reports an annotation the record cannot hold: attached to no citation, naming an undeclared relation, pointing into the wrong scheme, naming no local document, or contradicting a single-valued field.
