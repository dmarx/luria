The rename [#29](https://github.com/dmarx/luria/issues/29) asked for is done, executed by the machinery [ADR-040](../../record/decisions.d/ADR-040.md)
specified: one spec file (`record/migrations.d/0001-…toml`), one `luria
migrate 0001 --commit`, ten documents moved and stamped, 699 rewrites in
117 files, the blame-ignore commit appended automatically. The
acceptance question from [#55](https://github.com/dmarx/luria/issues/55) was whether the run would need hand edits
beyond the spec. The honest ledger:

**What the machinery did alone:** the config section renames in both
tomls (SG's `document =` line untouched by the section-aware pass, LU's
followed), the full sweep — codes, anchors in both spellings, view
paths outside URLs, composed LU codes, journals and CHANGELOG included —
the `git mv`s, the `formerly:` stamps, the old view's removal, and the
blame-ignore bookkeeping.

**What preceded it, by design:** a fixture-doctrine cleanup. Executing
the migration surfaced every test fixture and docstring example that had
borrowed real-sequence DP codes — the exact hazard the fixture-codes rule
(learned on [ADR-032](../../record/decisions.d/ADR-032.md)) exists for. Those became `VP` fixtures and OLD/NEW
placeholders *before* the run, so the mapping never had to know about
them. The migration suite itself opts out via `unlinted-file`, and the
sweep now honors that directive: a quote is not an address.

**What the run caught, live — three guards fired the day they shipped:**

1. **The sweep tried to rewrite the `formerly:` stamps** it had just
   written, in the first test run — masked structurally, because a later
   migration corrupting an earlier one's trail would erase the alias map
   at the source.
2. **The fixer had the same bug from the other side:** `luria link
   --fix`'s modernize pass rewrote the stamps into self-references
   (`GP-4` formerly `GP-4`) on the real corpus. Frontmatter is data;
   modernize now masks it, summary excepted.
3. **The scan counted each stamp as a legacy citation of itself** —
   every migrated document warning about its own former name forever.
   A document's own past is now exempt, one hop beyond the existing
   self-citation rule.

**The residue:** exactly one string in the corpus fell between the
sweep's patterns — a bare `"dp-4"` dict literal in a test assert, no `#`
and no `name="` to claim it. One human edit against 699 mechanical ones,
and the pattern that missed it is knowable in advance: an anchor quoted
*as a value* has no context marker. The template's five seed principles
also moved by hand — the template is in effect a downstream project, and
downstream replay is rung 3, deferred on purpose.

The tree ends the day with one spelling: `luria lint` green, zero
legacy-spellings warnings, 313 tests passing, and the journals citing
GP codes they never wrote — which is the full-rewrite doctrine working
exactly as decided, history staying greppable rather than sacred.
