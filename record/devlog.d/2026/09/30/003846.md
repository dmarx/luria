---
title: 'Relation annotations: the arrow notation, replaced by the field name'
created: '2026-09-30T00:38:46'
tags: []
---

**The first notation was the issue's arrow, and it was wrong in a
specific way.** [#333](https://github.com/dmarx/luria/issues/333) proposed `[[X]]{--F-->here}`, and the first
implementation shipped it alongside a mirror form `{here--F-->}` for the
other direction. Asked to reconsider the notation, the weakness was
direction. An arrow makes the author choose which way an edge runs, but a
relation already carries its direction in its name: `extends` and
`extended_by` are the same edge read from each end. Naming *this*
document's field (`[[extends::X]]`) says everything the arrow said, with
nothing left to get backwards. The one case lost is naming, from here, a
relation that only the cited document's scheme declares. That is the case
where no converse is declared, and [ADR-084](../../record/decisions.d/ADR-084.md) already treats an undeclared
converse as an edge the record has chosen not to know.

**The title slot came from asking where the relation goes after
`link --fix`.** Wikilinks are what an author types, not what is committed:
the fixer expands them. The arrow survived expansion by sitting outside
the link, which also meant it rendered as literal braces in every view. A
markdown link title is the one slot every renderer already has for
metadata, so `[[extends::X]]` expands to `[X](X.md "extends")`. The
relation then shows on hover and nowhere else. The title counts as a
relation only when it is shaped like a field name, and no link in this
repository had a title at all, so nothing existing is read differently.

**Using the title slot exposed four link patterns that assumed there is no
title.** The target checker, the remote hand-link check, view-citation
retargeting and the site's frontmatter link rewriting all matched
`\(([^)\s]+)\)`, so a titled link was not a link to any of them. For
the target checker that meant a broken path in a titled link was never
reported. All four now accept an optional title, and a test pins the target
checker.

**Fired again on `examples/constitution`** (scratch copy, `explain: true`
on `grounds`). The counts matched the arrow version: 4 citations named, 7
unexplained, 1 relation pushed up, 1 bad (`overrides` on a practice). The
committed form reads `[VALUE-001](../../docs/values.md#value-1 "grounds")`.
