Wrote a conceptual paper about the record (`docs/paper/`). What is worth
keeping from doing it:

**Where it lives was a test, not a taste.** A bare `ADR-001` in a top-level
`paper/x.md` produced no finding and no request to link; the same text under
`docs/` is linted. Fired before choosing, because the whole point of the paper
is that its sentences depend on the record. Decision: the new ADR on filing a
manuscript under `docs/`.

**The directive-scope trap, hit for real.** The first draft acknowledged
retired citations with line-scoped `inactive-ok:` comments at the top of the
file and cited the same decisions further down. The lint reported three
retired citations unacknowledged *and* three directives that no longer apply.
Both halves are the design working; the fix is `inactive-ok-file:` when a page
cites a retired decision more than once. A mention of a Proposed principle in
backticks was still reported as a citation (the paper names it once, as a
proposal), so it carries a file-scoped acknowledgement too. I did not
investigate why the backticks did not mask it; if that is a bug it is a
separate one.

**Pandoc trap.** `pandoc metadata.yaml 0*.md ...` parses the YAML as a
markdown document and defaults the title to "metadata". It needs
`--metadata-file=metadata.yaml`. The README's recipe was run verbatim after
the fix and builds HTML and docx; no PDF, since there is no TeX here.

**Citations.** Every DOI cited was checked against Crossref (nine of them from
memory first; all matched). Books, the Kunz and Rittel working paper, Borges,
Neurath, Quine, Gärdenfors (1990) and Nygard were not verified against
anything and the references page says so. An author-year citation script found
no dangling citations; it is not committed.

**An inconsistency found and left.** The reference documentation says journal
entries are never revised, while [DP-017](../../record/principles.d/DP-017.md) says even journals are rewritten when a
code is renumbered. The paper names the tension (forgetting section) rather
than resolving it; the docs have not been reconciled.

**Environment.** `pip install -e .` failed on `antlr4-python3-runtime` under
the system setuptools; a fresh venv installed it cleanly. Baseline before any
edit: `luria lint` exits 0 with warnings, including two relation statements in
[ADR-122](../../record/decisions.d/ADR-122.md) that the record cannot hold as written. Those predate this change.
