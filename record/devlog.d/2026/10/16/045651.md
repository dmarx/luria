`CLAUDE.md` named the generated files by hand, in a bullet saying never to
edit them. The generator already knew the list, but only as a chain of
special cases in `Config.is_generated`. `Config.generated()` now names each
target with a label: one file, or a directory whose pages are all
generated. `is_generated` asks those targets, and a template prints them,
so the check and the bootloader read one list ([DP-004](../../record/principles.d/DP-004.md)).

Trap for the guard: `adr_index.outputs()` includes nested records' views
([ADR-078](../../record/decisions.d/ADR-078.md)), rendered under each record's own config. The parent's targets
never covered them, before this change or after it. A property test that
iterates the parent's outputs therefore reports 133 "uncovered" example
pages. The test asks each record about its own outputs, under its own
config.
