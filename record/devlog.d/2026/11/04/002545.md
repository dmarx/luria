`luria repair --prune_stale` (`luria/prune.py`, [ADR-138](../../record/decisions.d/ADR-138.md), [#385](https://github.com/dmarx/luria/issues/385)) removes
acknowledgement codes that answer for no site, and deletes a directive left
naming nothing.

**Fired on a real case before trusting it.** This ran on a scratch worktree
of Nucleation at the head of [dmarx/nucleation#391](https://github.com/dmarx/nucleation/pull/391), after that PR had
removed its 69 wholly unused directives by hand. It found 336 idle codes in
262 files, all in directives that were otherwise in use, and none of them
whole directives. That matches a count taken independently, from
`Citation.excused_by`, before the module existed. The guard's re-scan found
the loud citations unchanged, `stale_annotations()` was 0 before and after,
and a second run found nothing. The sampled diffs removed only the idle
code and left the reason text as it was.

**The guard was fired on a sabotaged prune**
(`test_the_guard_restores_the_files_when_a_finding_changes`). `_idle` is
patched to call every code idle, so a directive that is answering for a
citation gets removed. The re-scan sees the citation go loud, restores the
file, and raises with the code named.

**Traps.**

- `used(ann)` is per directive. A per-code question has to go through
  `excused_by`, and that is matched by identity (`id(ann)`), since
  `Annotation` is a frozen dataclass whose equal copies would collide.
- Findings are compared by (file, code) count, not by line. Deleting a
  directive line moves every citation under it, so a by-line comparison
  fails on every whole-directive removal.
- `mention-ok` cannot use `excused_by`. The acknowledgement program gives a
  site to the first state-claiming directive and to a `mention-ok` only
  failing that. A mention whose site an `inactive-ok` holds today looks
  idle, and deleting it would lose the cover [ADR-105](../../record/decisions.d/ADR-105.md) wants when the document
  goes Active.
- A first draft found the cited codes per directive by scanning every site.
  That is quadratic: six thousand directives against the whole record's
  sites. The sites are indexed by file first.
